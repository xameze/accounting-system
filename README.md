# Система учета учетных записей организации

## Назначение

Приложение предназначено для учета учетных записей сотрудников в информационных системах организации. Оно помогает фиксировать, к каким системам имеет доступ пользователь, какой у учетной записи статус и когда истекает срок ее действия.

## Целевая аудитория

- системные администраторы;
- специалисты по информационной безопасности;
- сотрудники HR-отдела;
- руководители подразделений.

## Предметная область

Учет учетных записей пользователей в различных информационных системах организации. Каждая учетная запись привязана к пользователю, системе и имеет статус: активна, заблокирована, истек срок действия.

## Основные сущности

- Пользователь
- Система
- Учетная запись
- Статус

## Основные функции

- Формирование логина из ФИО пользователя.
- Получение описания статуса учетной записи.
- Проверка сложности пароля.
- Проверка доступа к системе по статусу учетной записи.
- Расчет количества дней до истечения срока действия учетной записи.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и аутентификации;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
# Система учета учетных записей организации

Консольное приложение для учета учетных записей сотрудников
в информационных системах организации.

## Возможности

- просмотр пользователей;
- просмотр учетных записей с расшифровкой статуса;
- поиск учетной записи по логину;
- отбор учетных записей по статусу;
- просмотр скоро истекающих учетных записей;
- добавление пользователей и учетных записей;
- блокировка и удаление учетных записей;
- сохранение данных в JSON-файлах между запусками.

## Структура проекта

- `main.py` — точка запуска, меню, вывод данных;
- `users.py` — функции работы с пользователями;
- `systems.py` — функции работы со справочником систем;
- `accounts.py` — функции работы с учетными записями;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод с обработкой исключений;
- `data/` — JSON-файлы данных (users, systems, accounts);
- `tests/` — автоматизированные тесты pytest.

## Формат данных

- `data/users.json` — список словарей пользователей;
- `data/systems.json` — список словарей систем;
- `data/accounts.json` — список словарей учетных записей.

Каждая учетная запись содержит поля: `id`, `user_id`, `system_id`,
`login`, `status`, `created_at`, `expires_at`.

## Требования

- Python 3.10+;
- pytest;
- flake8.
