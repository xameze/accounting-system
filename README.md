# Система учета учетных записей организации

## Назначение

Приложение предназначено для учета учетных записей сотрудников в информационных системах организации. Оно помогает фиксировать, к каким системам имеет доступ пользователь, какой у учетной записи статус и когда истекает срок ее действия.

## Целевая аудитория

- системные администраторы;
- специалисты по информационной безопасности;
- сотрудники HR-отдела;
- руководители подразделений.

## Предметная область

Учет учетных записей пользователей в различных информационных системах организации. Каждая учетная запись привязана к пользователю, системе и имеет статус: активна, заблокирована, истек срок действия.

## Основные сущности

- Пользователь
- Система
- Учетная запись
- Статус

## Основные функции

- Формирование логина из ФИО пользователя.
- Получение описания статуса учетной записи.
- Проверка сложности пароля.
- Проверка доступа к системе по статусу учетной записи.
- Расчет количества дней до истечения срока действия учетной записи.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и аутентификации;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
